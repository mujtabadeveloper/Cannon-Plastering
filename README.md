# Cannon Plastering

Responsive static website with interactive CSS 3D effects, animations and WhatsApp enquiry form.

## GitHub
Extract this ZIP and upload its contents to the root of a GitHub repository.

## Vercel
Import the repository. Select Other as framework. Leave build command empty and use . as the output directory. No installation is needed.

## GitHub Pages
In repository Settings > Pages, deploy from the main branch and / (root).

## Local preview
Open index.html, or run python -m http.server 8000 in this folder.

Edit index.html to change content, styles, animations and business details. Logo is in assets/logo.png. Google Fonts requires an internet connection; system fallback fonts are included. The enquiry form opens WhatsApp for the visitor to send their message. No backend is required.
